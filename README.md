# Fully Functional Calculator

A simple yet fully functional calculator built using **HTML**, **CSS**, and **JavaScript**. This calculator supports core mathematical operations such as **addition**, **subtraction**, **multiplication**, and **division**. Additional features include **on/off control**, **clear display**, and **backspace functionality** for a smooth user experience. The user interface is designed to be responsive and intuitive, ensuring seamless interaction on both desktop and mobile devices.

## Features

- **Basic Mathematical Operations**:
  - **Addition**: Add two or more numbers.
  - **Subtraction**: Subtract numbers.
  - **Multiplication**: Multiply numbers.
  - **Division**: Divide numbers.
  
- **Additional Functionalities**:
  - **On/Off Control**: Turn the calculator on or off.
  - **Clear Display**: Clear the calculator display with a single click.
  - **Backspace**: Remove the last entered character with the backspace button.
  
- **Responsive UI**: The layout is responsive, ensuring it works on both desktop and mobile devices.

## Technologies Used

- **Frontend**:
  - HTML (structure of the calculator)
  - CSS (styling and layout of the calculator)
  - JavaScript (functionality and interaction)
